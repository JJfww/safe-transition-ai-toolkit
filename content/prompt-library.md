# Prompt Library

Status: draft

The prompt library is meant to support staff planning and instructional preparation. Prompts should be treated as starting points, not finished products.

## What this page helps staff do

This page gives staff structured starting language for common transition-support tasks. It is meant to reduce blank-page time while keeping review, editing, and contextual judgment with the educator or support team.

## Prompt categories

- Plain-language rewrite
- Hidden curriculum analysis
- Role-play generation
- Job coach support
- Discussion questions
- Task analysis drafting
- Family communication support

## What still requires human review

- Whether the prompt request is clear and appropriate for the situation
- Whether the output needs correction, simplification, or context
- Whether the final result reflects respectful language and realistic expectations

## Information staff should not enter casually

- Student names and direct identifiers
- Protected records or IEP content
- Sensitive family details
- Employer-sensitive information
