# Use AI For This

Status: draft

These are lower-risk ways AI may support transition work when educators still review the output carefully and avoid entering protected or identifying information.

## What this page helps staff do

This page helps staff identify uses where AI can be a planning or drafting support without taking over high-stakes judgment. It is meant to save preparation time while keeping review and adaptation in human hands.

## Example use cases

- Rewrite information in plain language
- Create job-specific vocabulary practice. **Example:** [Open bakery vocabulary example (PDF)](Visual%20Supports/VocabularyList.pdf)
- Draft interview practice questions. **Example:** [Open cafeteria interview-practice example (PDF)](Visual%20Supports/Cafeteria-InterviewQuestions.pdf)
- Brainstorm visual supports. **Example:** [Open visual-support example](Visual%20Supports/WorkExperienceOptions.png)
- Create task analysis drafts
- Generate role-play scenarios
- Draft family-friendly explanations of transition services
- Identify possible hidden curriculum in job materials
- Support planning for community-based instruction

## Visual-support example prompt

The following reviewed prompt created the linked visual-support example. The resulting visual is still a draft to review and adapt for the real learner and setting.

```text
Create an 11 x 8.5 inch landscape, photo-realistic visual that compares two work-experience options for a student. Divide the page into two equal sections with clear headings, short student-friendly text, and several small, realistic photos. Do not use a cartoon style or real names.

Left section: Adaptive PE Aide
- Work with elementary or middle school students during activities.
- Help with activities and equipment.
- May be assigned to partner with one student.

Right section: Elementary Science Classroom Aide (K-2)
- Help set up materials.
- Help young students as directed by the teacher.

Use an easy-to-scan, professional layout with the words included on the visual.
```

## Bakery vocabulary example prompt

The following reviewed prompt created the linked bakery vocabulary example. Check the final visual against the student's real tasks before using it for instruction.

```text
Create a one-page, letter-size vocabulary visual for a student beginning work in a bakery. Use a clean, easy-to-scan layout with photo-realistic pictures and a printed word for each term. Do not use a cartoon style, real names, or identifying information.

Include these bakery words:
- Proofing
- Dough
- Yeast
- Convection oven
- Shape
- Rise
- Knead
- Mixer
- Dough hook

Use one clear image per word, plain-language labels, and high-contrast, readable text. Show real bakery equipment and processes, not decorative food imagery. Keep the page suitable for printing and reviewing with a student.
```

## Cafeteria interview-practice example prompt

The following reviewed prompt created the linked interview-practice example. Revise questions for the actual role and help the student prepare truthful, personal responses.

```text
Create a printable PDF with general interview-practice questions for a student in an 18-21 transition program who is interested in working in a nursing-home cafeteria. This is an instructional practice tool, not an employment screening or a prediction of what an employer will ask.

Use clear, student-friendly language and include questions about introductions, interest in the job, availability, following directions, teamwork, food safety, helping customers, and what to do when the student is unsure. Keep the questions appropriate for a cafeteria setting and leave space for a student or staff member to practice answers. Do not include student names, health information, or details about residents.
```

## What still requires human review

- Whether the output matches the real workplace, community setting, or support need
- Whether the language is respectful, clear, and age-appropriate
- Whether the suggested examples are realistic for the student or instructional context
- Whether any of the draft content should be revised before sharing with a student or family

## Information staff should not enter casually

- Student names or identifiable details
- IEP information
- Detailed assessment results tied to a specific student
- Private family details
- Employer-sensitive material that is not meant to leave the workplace context
